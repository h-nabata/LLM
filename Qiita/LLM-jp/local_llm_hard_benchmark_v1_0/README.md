# Local LLM Benchmark (HARD)

Qiita記事で使用したローカルLLMベンチマーク用の**精選問題**一式です。

LLMの高度な推論性能テストのために8分類、各8問からなるオリジナルの上級問題リストを作成。

ベンチマーク用の問題はすべて英語を入力言語としました。ただし、固有名詞や文学に関する問題では文中に漢字や日本語を含む場合があります。出力言語に関する指示はプロンプトに含めていません。

ベンチマークテストでは数理的思考に重きを置き、理数系分野からはコーディングを含む情報科学、数学、物理学、化学、生物学の範囲で出題しています。
数学については「数学（代数・数論）」、「数学（解析・幾何）」の2分野でそれぞれ8問を出題。いずれも大学入試～国際的な数学コンテストで通用するレベルの問題です。

その他の理系分野についても、教養～学部レベルの知識が要求される問題を収集・作問しています。
入試問題から抜粋・改変したもの以外に、ChatGPT-5.6-Solが提案したものを筆者が改訂する形で作成したため、完全にオリジナルの問題も含まれます。
